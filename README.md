# 🍔 Swiggy Sales Analysis Dashboard

An Excel-based interactive dashboard created to analyze Swiggy sales performance across different months, restaurants, ratings, and business states.

## 📌 Project Overview

This project focuses on converting sales data into an interactive Excel dashboard using Pivot Tables, Pivot Charts, slicers, and visualizations.

The dashboard provides a summarized view of sales performance and customer-related metrics for FY 2025–26.

## 🎯 Project Objectives

- Analyze monthly sales performance
- Understand average order value
- Analyze restaurant-wise sales
- Identify top-performing business states
- Analyze customer rating categories
- Identify low-rated food categories
- Provide an interactive view of sales performance

## 📊 Dashboard Analysis

The dashboard includes:

- Month-wise Sales
- Average Order Value
- Rating Summary
- Low Rating Category Analysis
- Top 5 Restaurants
- Top 5 Business States
- Bottom 2 Business States
- Month-wise Order Analysis

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Dashboard
- Data Visualization

## 📈 Key Features

### Interactive Filters

The dashboard includes slicers for:

- Month
- State
- Rating

These allow users to dynamically filter the dashboard and explore different segments of the data.

### Visualizations

The dashboard contains multiple visualizations covering:

- Sales trends
- Restaurant performance
- State-wise performance
- Rating distribution
- Order trends
- Low-rating categories
